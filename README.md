# Delphi

Помощник для проверки реорганизации: сравнивает документы «До / После», показывает изменения обязанностей и связывает выводы с исходными пунктами.

**Статус:** подготовлен backend на FastAPI и PostgreSQL: парсеры документов, сравнение функций, проверка источников, ручная проверка выводов, переводы и HTML/CSV-отчёты. Работа полного сценария с PostgreSQL и реальной AI-моделью ещё не подтверждена.

Для локальной проверки из `backend/`, после установки зависимостей через `uv sync --frozen`:

```sh
uv run ruff check app scripts migrations tests
uv run pytest -q
uv run --no-sync python scripts/export_openapi.py
```

Эти проверки не запускают PostgreSQL или AI и не доказывают качество семантического сравнения. Демонстрационная пара — исходные DOCX редакций 8/9; синтетические примеры хранятся отдельно. Сканы без OCR и отсутствующие приложения остаются ограничениями; рабочая область общая, авторизация пока не реализована.
