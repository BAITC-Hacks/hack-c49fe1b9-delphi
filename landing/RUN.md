# Delphi: отдельный лендинг

Самостоятельный сайт в `landing/`. Не меняет маршруты и код приложений `demo-frontend/` и `frontend/`.

## Локальный запуск

```sh
cd landing
npm install
npm run dev
```

Откройте http://localhost:5175. Интерактивное объяснение работает без сервера и модели.
Кнопки открытия примеров ведут в отдельное приложение, по умолчанию http://localhost:5173.
Для них нужно запустить `demo-frontend/` отдельно.

## Адрес демонстрации

Перед сборкой задайте `VITE_DEMO_URL`, например в `landing/.env.local`:

```dotenv
VITE_DEMO_URL=https://your-demo.example
```

Это адрес корня демонстрации. Ссылки `/new` и `/analyses/…` добавляются к этому адресу.
«История анализов» ведёт на корень демонстрации. Логотип возвращает на главную лендинга.

## Сборка

```sh
npm run build
npm run preview
```

Готовые файлы находятся в `landing/dist/`. Пути ресурсов относительные, поэтому сайт можно
размещать в корне домена или в подпапке. React, иконки и шрифт входят в сборку;
внешний CDN для работы страницы не нужен. `npm run typecheck` проверяет TypeScript.
