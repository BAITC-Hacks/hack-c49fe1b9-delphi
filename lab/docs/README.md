# Рабочие документы lab

Здесь хранятся handoff, результаты исследований и предложения по лаборатории. Сравнение с `origin/main` **09cc7b2** от 23.09.2026 — исторический снимок, а не текущий статус продукта.

**Текущая работа:** фаза 1 переносит наработки lab в основной backend и существующий frontend. Новые live-вызовы и E2E не входят в эту задачу; отдельный demo-дизайн — будущая фаза 2. В `lab/` уже реализованы и проверены подставными SDK-ответами извлечение с контекстом, структура и функции, поиск по исходным Before/After, риски, checkpoints/resume и перевод сохранённых пояснений. Новый синтетический live остановлен до полного результата; его точный статус и неизвестная полная стоимость принадлежат [handoff](handoff.md).

Лаборатория остаётся исследовательским компонентом с SQLite и строковыми ID.
Продуктовая реализация переносится в собственные модули FastAPI/PostgreSQL,
сохраняя UUID, замороженные источники и типизированный OpenAPI. Прямой импорт
lab JSON и замена продуктового хранилища не выполняются. Текущий frontend
подключается к продуктовым контрактам через HeyAPI, не к API лаборатории.

## Правила дальнейшей работы

1. Перед продолжением читать handoff и актуальный корневой [AGENTS.md](../../AGENTS.md).
2. Основные контракты продукта принадлежат [backend/openapi.json](../../backend/openapi.json), [docs/architecture.md](../../docs/architecture.md) и соответствующим backend-схемам. Лаборатория не задаёт альтернативный контракт для frontend; локальные изменения текущего поручения не заменяются историческим снимком remote.
3. Lab-заметки хранятся в `lab/docs/`. Разрешённая текущая интеграция меняет продуктовый backend, текущий frontend и их owning-документы; прежний запрет продуктовых правок относился только к историческому исследованию. Demo-дизайн остаётся отдельной будущей задачей.
4. [lab/README.md](../README.md) — входная инструкция лаборатории: команды, ограничения и текущие проверки. Статус всего продукта берётся из [docs/README.md](../../docs/README.md), а не из старого снимка сравнения.
5. Различать «есть в коде», «проверено подставными ответами» и «подтверждено live». Статус общего переноса подтверждается отдельными продуктовыми проверками; успешные lab-тесты не считаются результатами backend/frontend.
6. Ключи, полные запросы и документы не копировать в handoff. Локальные результаты остаются в `lab/data/`, журналы стоимости — в `agent_costs/out/lab/`.

Последний общий lab-прогон: 93 теста, 92 успешных и один существующий
необязательный пропуск. Продуктовые парсеры отдельно прошли 38 тестов и Ruff.
Общий итог текущей интеграции ведётся в [backend README](../../backend/README.md),
[плане](../../docs/implementation-plan.md) и [frontend README](../../frontend/README.md).
