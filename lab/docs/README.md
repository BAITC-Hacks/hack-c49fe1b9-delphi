## Правила дальнейшей работы

1. Перед продолжением читать handoff и актуальный корневой [AGENTS.md](../../AGENTS.md).
2. Основные контракты продукта принадлежат [backend/openapi.json](../../backend/openapi.json), [docs/architecture.md](../../docs/architecture.md) и соответствующим backend-схемам. Приоритет у актуальной версии из remote. Лаборатория не задаёт альтернативный контракт для frontend.
3. Новые заметки, сравнения и планы этой ветки работы складывать в `lab/docs/`. Общие `docs/`, `backend/` и `demo-frontend/` в рамках текущего поручения не редактировать. Предложения владельцам этих частей записывать со ссылками на исходный код.
4. [lab/README.md](../README.md) остаётся входной инструкцией лаборатории. Его описание старого стека и прежнего состояния репозитория не заменяет обновлённые общие контракты; расхождения разобраны в alignment.
5. Различать «есть в коде», «проверено подставными ответами» и «подтверждено live». Предложение из alignment не считается реализованным переносом.
6. Ключи, полные запросы и документы не копировать в handoff. Локальные результаты остаются в `lab/data/`, журналы стоимости — в `agent_costs/out/lab/`.

После pull выполнялся анализ файлов и Git-состояния. Сервисы, сборка, новые тесты и платные запросы не запускались.
