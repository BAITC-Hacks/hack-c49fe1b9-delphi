## Продуктовая интеграция

[Alignment](backend-lab-alignment.md) описывает границы переноса. Основной продукт
сохраняет PostgreSQL, UUID, типизированный OpenAPI, один worker и один ограниченный
агент. SQLite лаборатории остаётся только исследовательским хранилищем.

Перенос парсинга проверен отдельно: **38 backend parser-тестов** с настоящими DOCX
и синтетическими документами; Ruff для парсеров и этих тестов проходит. Сохранены
точные цитаты, структурированные locator, родительские ключи и продуктовая выдача
UUID. Исправлены контекст ненумерованных ролей, неоднозначный TOC и табличные
заголовки; добавлены ограничения Office/XML, PDF, XLSX и извлечённого текста.

Статус общей проверки агента, checkpoints/resume, перевода, API и текущего
frontend ведётся в [backend README](../../backend/README.md),
[плане](../../docs/implementation-plan.md) и [frontend README](../../frontend/README.md).
Успешный тест lab не переносится автоматически на продукт. Свежая фаза не включает
новый live или браузерный E2E; прежние браузерные результаты остаются историческими.

## Воспроизводимые локальные команды

Обычный Windows launcher импортирует `agent_costs` без ручного `PYTHONPATH`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 demo --mode preprocess --allow-limited
```

macOS/Linux, из корня репозитория после установки зависимостей по
[lab README](../README.md):

```sh
cd lab
PYTHON_DOTENV_DISABLED=1 .venv/bin/python -B -m unittest discover -s tests -v
PYTHON_DOTENV_DISABLED=1 LAB_DATA_DIR=.tmp/preprocess-check .venv/bin/python -B -m delphi_lab demo --mode preprocess --allow-limited
```

`LAB_DATA_DIR` должен указывать на новый каталог внутри `lab/`; не используйте
историческую базу для контрольных запусков. `preprocess` не делает AI-запросов.
Отдельный launcher `python -m agent_costs.lab_run` не нужен. Не включайте секреты,
промпты и содержимое документов в журналы стоимости.

Из `backend/`:

```sh
uv run --offline pytest tests/test_parsers.py -q
uv run --offline ruff check app/parsers tests/test_parsers.py
```

Дальнейшая живая оценка требует отдельной задачи с выбранным корпусом и бюджетом;
первым делом проверяются незавершённые вызовы и UNKNOWN в соответствующем run.
Техническая готовность resume сама по себе не запускает платное продолжение.
