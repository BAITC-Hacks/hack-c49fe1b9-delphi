## Состояние кода лаборатории

Ранее интегрирован существующий `agent_costs` в каждый фактический вызов Responses API через `delphi_lab/agent.py` и адаптер `delphi_lab/costs.py`. Обычный `lab/run.ps1` импортирует пакет без ручного `PYTHONPATH`. Сохраняются отдельные попытки/раунды, полный usage и метаданные; промпты, документы и ключи не записываются в журнал стоимости. Цены — `agent_costs/examples/prices.openai-gpt6-sol.json`, выбор тарифа — существующий `response_prices`. Старый launcher не нужен.

Добавлены продолжение сохранённого run и денежный ограничитель:

- `resume` использует тот же run_id, принятые блоки/функции/выводы и накопленные вызовы; повторное извлечение принятых блоков не требуется.
- При продолжении оставшиеся extraction-партии ограничены восемью блоками. Исходные промпты, output-limit и retry-настройки сохранены.
- `LAB_COST_BUDGET_USD` резервирует верхнюю оценку стоимости перед запросом через тот же калькулятор; резервы переживают остановку процесса.
- CLI поддерживает `resume RUN_ID --max-calls 600 --timeout-seconds 7200 --cost-budget-usd 10`. Это подготовленная возможность, **не выполненный второй запуск**.
- Изменения затрагивают `lab/delphi_lab/agent.py`, `pipeline.py`, `__main__.py`, `costs.py`, `lab/tests/test_resume_budget.py`, `lab/.env.example` и `lab/README.md`. Настоящий `.env` не редактировался.
