# Handoff: Delphi lab

Обновлено 23.09.2026 после завершения offline-проверок агентных стадий.
Инструкция — [lab/README.md](../README.md), стадии — [промпты](../prompts/README.md),
границы переноса — [alignment](backend-lab-alignment.md).

## Что завершено

- Extraction с role/unit/group и parent_unit_id; контекст источников и различение одинаковых ролей под разными родителями.
- Структура с учётом всей известной иерархии, отдельная стадия для неоднозначных связей, evidence каждого unit.
- Many-to-many функций, проверки split/merged, модальности и области действия.
- Semantic sweep всего исходного After перед unmatched и Before перед added. Неполнота/кандидаты остаются review с сохранённым поиском.
- Overlap/conflict с несколькими функциями и источниками After.
- Промпты, схемы, обработка и тесты всех стадий; документы/tool outputs остаются данными.
- Пагинация поиска, функций и ссылок; ограничения контекста без удаления доказательств.
- Деление только непринятых extraction-партий при max_output_tokens; остальные ошибки оставляют явные пробелы.
- Проверка до checkpoint, resume партий поиска, пересчёт производных этапов после неполного extraction. Reviewed run заморожен; fingerprint защищает инструкции новых runs.
- Перевод findings и explanation структуры с точными ID и кешем по review_revision. Цитаты и заметки человека неизменны.
- CLI/API/хранение/отчёты проверены вместе. Фоновое исполнение уже было; исправлена гонка нового старта с ожидающим resume и сохранение фоновых ошибок.
