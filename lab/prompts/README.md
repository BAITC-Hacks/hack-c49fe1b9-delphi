# Промпты лаборатории

`system.md` применяется ко всем модельным запросам. Документы, имена, цитаты,
поля функций и ответы инструментов являются данными, а не инструкциями.
Промпты не содержат готовых ответов из fixtures или реальных редакций 8/9.

| Этап | Файл | Схема в agent.py | Проверка кода |
|---|---|---|---|
| Извлечение | [extract.md](extract.md) | `_Extraction` | Все primary IDs ровно один раз; primary evidence, владельцы и ациклические родители |
| Структура | [structure.md](structure.md) | `_Structure` | Каждый оставшийся unit/group ровно в одной связи; стороны и evidence каждого unit |
| Сопоставление | [compare.md](compare.md) | `_Comparison` | Target mapped либо unresolved; many-to-many; evidence каждой функции |
| Полный поиск исходников | [source_search.md](source_search.md) | `_SourceSearch` | Все IDs партии прочитаны; кандидаты из прочитанной партии; sweep ведёт код |
| Риски | [risks.md](risks.md) | `_Risks` | Все target After рассмотрены; overlap/conflict с двумя функциями и источниками |
| Перевод findings | [translation.md](translation.md) | `_Translation` | Тот же набор ID; только title, explanation, recommendation |
| Перевод структуры | [translation.md](translation.md) | `_StructureTranslation` | Тот же набор ID; только explanation |

`provenance.prompt_manifest()` сохраняет SHA-256 файлов при создании run. Resume
при изменении fingerprint отклоняется; старый снимок без него отмечается как legacy.
Промпты написаны на английском, язык пояснений — `ru|kk|en`. Названия и исходные
цитаты сохраняют свой язык. Краткие action/object/scope/condition модель формулирует
по-английски для поиска. Это не доказательство межъязыкового качества; казахский
текст остаётся черновиком до вычитки.

## Инструменты и покрытие

- `search_clauses(side, query, filters, offset)` — лексические кандидаты, не доказательство отсутствия.
- `get_clause(source_id)` — оригинальный фрагмент и родители; слишком большой ответ отклоняется явно.
- `get_unit_functions(side, unit_id, offset)` — извлечённые функции владельца.
- `check_references(document_id, offset)` — цели внутренних ссылок без смыслового вердикта.

Пагинированные ответы содержат `has_more` и `next_offset`; начальный offset — 0.
Инструменты доступны в structure/compare/risks. Extraction, source_search и
translation работают по переданным партиям. Оглавление не является доказательством.

Перед `unmatched` проверяются все доступные исходные body-блоки After, перед
`added` — Before, включая блоки без извлечённых функций. SourceSearch хранит
reviewed/candidate IDs, ошибки и complete. Пробел чтения, неполная партия или
возможный counterpart оставляет `review`, а не доказанную потерю/новую работу.

Структура сначала проверяет имя, тип и всю известную цепочку родителей, затем
отправляет оставшийся каталог на structure. Переполненный каталог остаётся
непроверенным с ошибкой, не обрезается. Риски используют ранжированных кандидатов,
не полный перебор всех пар. Покрытие обработки не является оценкой точности.

## Лимиты и сохранение

По умолчанию 40 вызовов, 900 секунд, 5000 output tokens, 4 tool rounds. Существующие
retries сохранены: SDK retries выключены, один повтор временной ошибки. На последнем
раунде `tool_choice=none`. История не удаляется: превышение контекста останавливает
партию с явным ограничением.

Extraction берёт до 16 primary-блоков (8 при resume), сохраняя родителей. Только
`incomplete/max_output_tokens` делит непринятую extraction-партию. Одиночный блок
остаётся с ошибкой; другие incomplete/refusal/неверные схемы не считаются успехом.
Неполный перевод не кешируется. Принятые результаты проверяются до checkpoint.

Resume повторяет незавершённые партии поиска, если extraction закончен. При
пробелах extraction функции сохраняются, а производные сравнения пересчитываются
после дополнения каталога. Проверенные человеком runs не возобновляются.

`test_agent_semantics.py`: 28 проверок через подставной SDK, без подмены всего агента.
Полный набор lab: 106 тестов прошли. Платный end-to-end не запускался; реальное
качество RU/KK/EN не подтверждено.
