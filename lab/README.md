# Delphi lab — документы и один AI-агент

Изолированная лаборатория обработки комплектов Before/After: парсеры, последовательный агент, источники, checkpoints/resume, ручная проверка, перевод и HTML/CSV. Код продолжается в `lab/`; результаты и экспериментальные контракты не подменяют основной продукт.

**Стек лаборатории:** Python 3.12, FastAPI, Pydantic, локальная SQLite и OpenAI Responses API. **Стек продукта** в [архитектуре](../docs/architecture.md) использует PostgreSQL; SQLite лаборатории не является fallback для backend. Выбранный продуктовый UI — Next.js с историей, загрузкой и тремя вкладками результата. API-консоль lab `/docs` и HTML-отчёт — отдельные средства проверки, не интеграция с этим UI.

Актуальные результаты проверок и границы live-прогона: [handoff](docs/handoff.md). Стадии/схемы: [библиотека промптов](prompts/README.md). Текущий перенос в продукт: [согласование с продуктом](docs/backend-lab-alignment.md).

## 1. Установка и бесплатный preprocess

Из корня репозитория в Windows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/bootstrap.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 demo --mode preprocess --allow-limited
```

На macOS/Linux эквивалентный запуск обычного CLI:

```sh
uv venv lab/.venv --python 3.12
uv pip install --python lab/.venv/bin/python -r lab/requirements.lock.txt
cd lab
.venv/bin/python -B -m delphi_lab demo --mode preprocess --allow-limited
```

`demo` по умолчанию читает **оба оригинальных DOCX редакций 8 и 9** из `docs/sources/`. Preprocess не вызывает модель или перевод: сохраняет документы, точные блоки, текстовые кандидаты и HTML/CSV. Сходство текста не является AI-выводом о сохранении или потере функции.

В проверенном парсинге этой пары 996 блоков: 30 блоков оглавления и 966 блоков основного текста. Пользовательские Word-стили оглавления распознаются по повторному заголовку и номеру страницы; исходные блоки и смещения сохраняются. Пустой пункт 5.5.3 и отсутствующее тело приложения 1 остаются ограничениями, поэтому нужен `--allow-limited`. Этот флаг не разрешает объявить непроверенную обязанность утраченной.

Данные по умолчанию находятся в `lab/data/`. `LAB_DATA_DIR` выбирает отдельную директорию **внутри `lab/`**; для приёмки использовались новые временные каталоги `lab/.tmp/`, не историческая база. CLI печатает путь к отчёту. Рядом сохраняются `result.json`, `sources.json` и `functions.csv`; после preprocess таблица функций содержит только заголовки.

## 2. Live-запуск только по отдельному разрешению

Ключ и модель читаются из существующего `lab/.env` (`OPENAI_API_KEY`, `OPENAI_MODEL`) или окружения. Ключ не выводится и не передаётся в промпты. Не перезаписывайте уже настроенный `.env`. Live отправляет выбранные документы провайдеру; `store=false` не является обещанием отсутствия хранения по всем политикам провайдера.

Начните с короткого явно синтетического комплекта; ожидания из `fixtures/expected.json` не передаются модели:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 demo --fixture ru --mode live
```

Пример явно увеличенных лимитов, только с согласованным бюджетом:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 demo --fixture ru --mode live --max-calls 600 --timeout-seconds 7200 --cost-budget-usd 50
```

Для оригинальной пары используйте `demo --mode live --allow-limited` с выбранными явными лимитами. Для своих файлов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 analyze --before before.docx --after after.docx --mode preprocess --allow-limited
```

`--before` и `--after` принимают несколько путей. Для KK/EN контрольных текстов предусмотрены `--fixture kk` и `--fixture en`; `--language` задаёт язык объяснений независимо от языка исходников. Синтетические входы описаны в [fixtures/README.md](fixtures/README.md).

По умолчанию остаются 40 запросов, 900 секунд на запуск, 5000 выходных токенов, 16 первичных блоков в партии и 4 раунда инструментов. Один временно неудачный API-запрос может повториться один раз; автоматические retries SDK отключены. `--max-calls` — число запросов, не денежный лимит. Большие документы могут потребовать существенно больше стартовых лимитов.

## 3. Как проходит анализ

1. Парсер сохраняет точный оригинальный текст, положение, иерархию и ограничения. Копия для поиска нормализуется отдельно. Текст документов — данные, не инструкции агенту.
2. `extract` получает первичные блоки и контекст родителей, извлекает подразделения/роли и атомарные функции с исполнителем, областью, условием и модальностью. Неустановленный владелец остаётся явной неопределённостью, не выдумывается.
3. `structure` сопоставляет подразделения/группы и иерархию. Должности не превращаются в созданные или упразднённые подразделения. Точное совпадение названия/типа/родителя не доказывает неизменность обязанностей.
4. `compare` строит many-to-many связи функций. Передача, разделение и объединение требуют доказательств с обеих сторон. Перенумерация не означает потерю.
5. Для неразрешённого соответствия `source_search` проходит **все доступные исходные блоки After**, включая пропущенные извлечением обязанности. Лексический поиск и просмотр только извлечённых функций не доказывают отсутствие.
6. `risks` проверяет обработанные After-функции на пересечения и потенциальные противоречия с учётом роли и области. Нужны минимум две After-функции и два источника. Ранжированные кандидаты и инструменты не являются исчерпывающей проверкой всех пар.
7. Для несопоставленной After-функции обратный `source_search` проверяет исходный Before. Только полный поиск без неразрешённых кандидатов позволяет `added`; неполный поиск остаётся `review` с покрытием и источниками.
8. Программа валидирует ID, стороны, владельцев, иерархии и смещения; цитаты извлекает из сохранённых источников. Принятые партии сохраняются через checkpoints. Финальный статус зависит от покрытия и ограничений, а не только от окончания цикла.

Инструменты чтения: `search_clauses`, `get_clause`, `get_unit_functions`, `check_references`. Коллекции используют `offset/next_offset/has_more`; неизвестные ID/инструменты и циклы родителей отклоняются. Доступа к shell или внешнему поиску у агента нет.

Все используемые стадии имеют файлы промптов и строгие схемы. `incomplete`-ответ не подтверждает покрытие; при лимите выхода извлечение может делить непринятую партию без увеличения заданных лимитов. Непрочитанный одиночный блок остаётся в coverage. Полная семантическая точность не следует из полного покрытия.

## 4. Сохранение, resume, review и перевод

Один анализ хранит один запуск и неизменяемый комплект документов. Повтор одинакового запроса старта идемпотентен; для новых входов создайте новый анализ. Одновременно допускается один процесс/активный запуск. После остановки принятые checkpoints сохраняются.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 history
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 show RUN_ID
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 estimate RUN_ID --resume
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 resume RUN_ID --max-calls 600 --timeout-seconds 7200 --cost-budget-usd 50
```

`estimate` бесплатен и показывает только нижнюю границу запросов извлечения, не цену или время завершения. `resume` сохраняет run ID, модель, источники и накопленный счётчик запросов. Он пропускает принятые партии; оставшееся извлечение использует до 8 блоков. Сохранённые частичные source-sweeps продолжаются с непроверенных блоков. Если новое извлечение расширило каталог, прежнее сопоставление/структура/риски пересматриваются, чтобы не сохранить устаревшее покрытие.

Возобновление отклоняется при изменении модели, состава документов, отпечатка промптов или после человеческой проверки. Старые запуски без отпечатка имеют явно отмеченную legacy-границу. Исторические результаты не мигрируются автоматически. `recover` помечает работу остановленного процесса interrupted; запускайте его только при отсутствии работающего CLI/API.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 review RUN_ID FINDING_ID confirmed --note "Проверено по источникам"
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 translate RUN_ID --language en
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 export RUN_ID --language en
```

Review меняет отдельное решение человека и атомарно повышает `review_revision`; AI-вывод и цитаты не переписываются. Перевод включает сохранённые title/explanation/recommendation findings и explanation структуры, кешируется по запуску/ревизии/языку и не повторяет анализ. Изменившиеся во время запроса review или ID блокируют сохранение устаревшего перевода. Перевод через модель тоже платный и требует разрешения; простой просмотр/экспорт нового языка не запускает его автоматически.

HTML и CSV строятся из сохранённого снимка. HTML показывает точные источники/контекст, структуру, findings, границы поиска, принятые/непроверенные/отклонённые решения и отдельный детерминированный текстовый diff. Отчёт не редактирует исходный Word.

## 5. Учёт стоимости и API

**Используйте обычный `lab/run.ps1`. Отдельный launcher `python -m agent_costs.lab_run` больше не нужен.** Адаптер `delphi_lab/costs.py` использует существующий `agent_costs`, без второго калькулятора и дополнительных модельных запросов.

Для каждой фактической попытки сохраняются run/stage, usage, время, модель/tier, retry/tool round, оценка USD или UNKNOWN. Обычный каталог — `agent_costs/out/lab/<run_id>/`; события не содержат ключей, промптов и документов. Preprocess и чтение кеша перевода не создают платных событий. Новые изолированные приёмочные прогоны могут направлять адаптер в собственный временный каталог; исторические журналы не редактируются.

`--cost-budget-usd` или `LAB_COST_BUDGET_USD` резервирует стоимость перед запросом по существующему тарифному снимку. Неизвестная стоимость не равна нулю. Ошибка метрик не вызывает платный retry; при денежном пределе дальнейшие запросы блокируются, если корректный учёт/резерв невозможен. Это оценка по сохранённым тарифам, не провайдерский инвойс. Политика retries и тарифный калькулятор в этой задаче не расширялись.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File lab/run.ps1 serve --port 8010
```

Откройте `http://127.0.0.1:8010/docs`. API предоставляет историю/загрузку, запуск/resume, структуру/функции/findings, источники/evidence, review, перевод, HTML/CSV и стоимость. Это локальная лаборатория без пользовательской авторизации, не готовый клиент основного backend. ID, enum, пути и локальное хранение требуют явного адаптера при интеграции; см. [alignment](docs/backend-lab-alignment.md).

## 6. Автоматические проверки без модели

Из `lab/` на macOS/Linux:

```sh
PYTHON_DOTENV_DISABLED=1 .venv/bin/python -B -m unittest discover -s tests -v
```

Windows PowerShell:

```powershell
Push-Location lab
$env:PYTHON_DOTENV_DISABLED = '1'
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
Remove-Item Env:PYTHON_DOTENV_DISABLED
Pop-Location
```

Тесты используют временные БД/журналы, блокируют внешнюю сеть и подставляют SDK. [test_agent_semantics.py](tests/test_agent_semantics.py) выполняет реальный код стадий, включая полный путь pipeline/Store → агент → review → отчёт → перевод; весь агент не заменяется заглушкой. Другие проверки охватывают оригинальные DOCX, синтетические PDF/XLSX, неизвестные ID/отсутствие доказательств, частичное покрытие, пагинацию, incomplete, resume, гонку перевода/review и существующий бюджет.

Фактически выполненные команды, счётчики и live-результат фиксируются в [handoff](docs/handoff.md). Подставные ответы не доказывают качество реального AI; один синтетический live-тест также не подтверждает качество на всей официальной паре и KK/EN.

## 7. Ограничения и следующие задачи

- DOCX: точный текст и локаторы абзацев/таблиц, без выдуманных страниц. Изображения, вложения, tracked changes и непрочитанный текст явно ограничивают покрытие.
- PDF: текстовый слой и номера страниц, без OCR; порядок колонок/таблиц требует проверки. XLSX: строки/адреса и базовый контекст колонок, без вычисления формул и чтения рисунков. Старые DOC/XLS не поддержаны.
- Парсер ограничен 20 MiB на файл, 80 MiB распакованного Office ZIP, 10 000 блоков/2 млн символов, 200 PDF-страниц, 20 XLSX-листов/10 000 строк/64 колонок. Текстовый diff имеет собственные пределы и перечисляет непроверенное.
- Отсутствующие приложения нельзя восстановить увеличением бюджета. Риски оцениваются по доступному комплекту, внешнее юридическое соответствие не выдумывается.
- Текущая фаза 1 переносит наработки в собственные модули основного FastAPI/PostgreSQL backend и существующий Next.js frontend. Продукт сохраняет UUID, свои enum/coverage, транзакции и OpenAPI; прямой импорт lab JSON или SQLite не используется. Статус проверок — в [backend README](../backend/README.md), [плане](../docs/implementation-plan.md) и [alignment](docs/backend-lab-alignment.md).
- Новые live-вызовы и E2E не входят в текущую фазу. Последний синтетический live остановлен до полного результата, стоимость содержит UNKNOWN; детали — в [handoff](docs/handoff.md). Полная семантическая приёмка и отдельный demo-дизайн остаются последующими задачами; demo-дизайн обозначен как будущая фаза 2 в текущем поручении.
