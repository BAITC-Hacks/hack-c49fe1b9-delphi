# Синтетическое положение — После

Учебный контрольный пример Delphi. Все подразделения и обязанности вымышлены; это не документ компании и не нормативный акт.

## 1. Руководитель отдела аналитики — должностная роль

1.1. Может ежегодно проверять полноту реестра рисков всей компании.

## 2. Руководитель отдела закупок — должностная роль

2.1. Обладает исключительным полномочием окончательно утверждать список поставщиков для закупок северного филиала; другие подразделения не вправе выполнять это утверждение.

2.2. Заключает договоры закупок северного филиала с утверждёнными поставщиками.

2.3. Самостоятельно проводит итоговый аудит соблюдения закупочных процедур по договорам северного филиала, которые сам заключил; независимая проверка другим подразделением не предусмотрена.

## 3. Руководитель отдела внутреннего контроля — должностная роль

3.1. Обладает исключительным полномочием окончательно утверждать список поставщиков для закупок северного филиала; другие подразделения не вправе выполнять это утверждение.

## 4. Директор северного филиала — должностная роль

4.1. Ежемесячно составляет отчёт об обучении работников только северного филиала.

## 5. Директор южного филиала — должностная роль

5.1. Ежемесячно составляет отчёт об обучении работников только южного филиала.

## 6. Координатор рисков — должностная роль

6.1. Обязан ежемесячно составлять сводный отчёт о рисках для всей компании и направлять его исполнительному директору.
