Приложение 1 с кодексом этики только названо в последнем абзаце DOCX; вложенного файла и содержания нет. Анализ не должен создавать это приложение или скрывать его отсутствие.

Языки RU/KK/EN, история анализов и детали UI — решения команды. В ТЗ организаторов нет требования трёх языков или сохранённой истории.

Исходники в sources и hackaton сохраняются без изменения. Контрольные модифицированные документы должны создаваться отдельно и называться синтетическими.

## 3. Ложные срабатывания, которых следует избежать

- Удаление фразы из одного пункта не доказывает потерю функции во всём комплекте.
- Квартальная/годовая отчётность остаётся в новой редакции, п. 5.1.6, несмотря на изменение формулировки у ДККМ.
- Старый анализ результатов непрерывного аудита у ДККМ, п. 5.5.4, нужно искать также в новой редакции, пп. 5.4.5 и 5.3.8.
- Общие задачи контроля качества сохраняются, включая п. 5.5.2 и разделы 10–11. Возможное исчезновение явно названных полномочий 5.6.2–5.6.3 не равно исчезновению всей функции.
- Права перенумерованы 5.8 → 5.7, запреты 5.9 → 5.8, обязанности 5.10 → 5.9, ресурсы 5.11 → 5.10. Номер сам по себе не определяет соответствие.
- Общие обязанности БВА и частная обязанность директора могут отражать иерархию, а одинаковые глаголы у разных подразделений — разные области работы.
- Реальная пара подтверждает передачу и изменение обязательности. Для безусловно заданной потери/дублирования/конфликта нужны отдельные подписанные синтетические примеры.

## 4. Парсинг настоящих DOCX

Ниже указаны позиции в редакции 8. В редакции 9 оглавление начинается с абзаца 475; сохраняется предупреждение об отсутствующем приложении 1. Контрольные пункты передачи 5.3/5.3.3 и изменения обязательности 9.15 проверяются и на DOCX, и на Markdown.

| Наблюдение | Следствие |
|---|---|
| В абзаце 122 вместе находятся 3.9, 3.10 и 3.11 | Делить по границам пунктов, сохраняя контекст и смещения |
| Заголовки 10–14 находятся внутри обычных абзацев 436, 450, 458, 468, 471 | Не полагаться только на Word-стили |
| Оглавление в абзацах 476–490 использует стили заголовков | Не создавать из него новые обязанности |
| В абзаце 188 буквально написано «5.5.3. ;» | Пустое содержание нельзя додумывать |
| Приложение 1 названо в абзаце 492 без вложения | Показывать отсутствие приложения |
| Нумерация пунктов набрана обычным текстом; родительские разделы задают исполнителя | Хранить пункт, подпункт и заголовок роли вместе |
| Метаданные Word указывают en-US/ar-SA при русском тексте | Определять язык по содержимому |
| Нет надёжной разметки страниц; метаданные дают Pages=1, Words=0 | Ссылаться на редакцию, пункт, абзац и положение фрагмента |
| Нет отслеживаемых вставок/удалений | Этот файл не проверяет поддержку режима исправлений Word |

Номера абзацев — позиции XML документа, включая пустой абзац; это не номера страниц. Для поиска нормализуем пробелы, но доказательства берём из сохранённого оригинального текста. Подпункты должны сохранять контекст исполнителя из родительского заголовка.

## 5. Контрольный пример передачи

В редакции 8 п. 5.4 задаёт директора ДНМ; п. 5.4.4 и подпункты описывают работу с результатами других субъектов внутреннего контроля и недостаточным/дублирующим покрытием рисков. В редакции 9 п. 5.3 и п. 5.3.3 закрепляют эту работу за новой группой руководителей с учётом их направлений.

Проверяем действие, объект и область ответственности вместе с новым исполнителем. Нельзя ограничиться совпадением текста подпункта или назначить всем директорам каждую функцию без контекста специализации.
