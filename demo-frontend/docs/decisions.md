- Отдача `demo-frontend/dist` бэкендом (`StaticFiles`) — зона бэкенда (`docs/handoff.md` §2).


### Исправление доказательств перед переносом Figma — 23 сентября 2026

- По согласованию база — `nurdaulet-api-integration` / PR #2; очередь и её новые файлы принадлежат ветке `nurdaulet-review-queue` и в этот коммит не входят. Изменения только в `demo-frontend/`.
- Пользовательская задача: проверить вывод по полному набору оригинальных цитат и сохранить решение без потерь. Обе стороны функции, исполнители, источники, участники риска и источники структуры — массивы. Контекст и ошибки evidence сохраняются. Поиск и общее покрытие — структурированные данные; контракт записан в README.
- Подсветка использует сохранённые offsets, с переводом Python code points в JS UTF-16. Неоднозначный поиск по тексту не выбирает случайное совпадение. Неверные offsets дают полный пункт и предупреждение.
- Панель не объявляет пустую неприменимую сторону «не найденной»; цитата из заключения не получает выдуманный статус «Сохранена». HTML учитывает отклонения, заметки и все источники, CSV сохраняет все стороны. Источник открывается по `?finding=`. Переносы в таблицах возвращают кнопки источников в видимую область; статус на телефоне не сжимает заголовок.
- Ошибка удаления файла останавливает запуск; успешные удаления сохраняются перед следующей попыткой. Ошибка истории отличается от пустой истории и имеет повтор загрузки.
- Проверено: production build, 14 регрессий evidence/offsets/coverage/export/API errors и удаления документов; браузер 1280 и 375 px, `/analyses/demo`, цитаты передачи, два источника «После», пустой фильтр и ошибка результата. Ширина таблицы 1214 px внутри контейнера 1214 px. Новый AI-прогон и сохранение review на живом сервере не выполнялись.
- Остаётся отдельному этапу дизайна: новая очередь и её сочетания клавиш, палитра V2, навигация и локализация RU/KK/EN. Не считать эти функции реализованными данным коммитом.
