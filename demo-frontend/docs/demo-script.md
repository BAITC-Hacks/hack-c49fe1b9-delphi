# Сценарий показа демо (90 секунд)

Демо работает без бэкенда: `cd demo-frontend && npm install && npm run dev` → http://localhost:5173. Перед записью нажмите «Сбросить решения примера» в очереди проверки или откройте окно инкогнито — решения из прошлого показа хранятся в браузере.

Главная мысль для жюри: **Delphi быстро показывает проверяемые изменения и вопросы, а решение принимает ответственный сотрудник, видя источник.**

## Если спросят

- **«Это реальный запуск?»** — Нет, демо показывает сохранённый результат и помечено бейджем. Живой анализ с моделью — в основном приложении `frontend/` на FastAPI.
- **«Почему «не найдено», а не «удалено»?»** — Анализ ограничен предоставленными документами. Поиск идёт по всему комплекту «После»; у синтетического примера видно покрытие: «Поиск по N пунктам, полный: да».
- **«Откуда цитаты?»** — Дословно из исходных документов; модель возвращает только ссылки на пункты, текст берётся из сохранённого оригинала.
